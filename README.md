# 한 판만

밤에는 세 장의 패로 짝을 맞춰 돈을 벌고, 낮에는 그 돈으로 어떤 인생을 살지 선택하는 복고풍 로그라이크입니다.

## 핵심 규칙

- 금화·장미·해골 중 같은 그림 2개면 당첨, 3개면 잭팟
- 원하는 패를 고정하고 나머지만 다시 뽑기
- 성공 후 수익 확정 또는 전부 다시 걸기
- 3판마다 규칙을 비트는 로그라이크 장치 선택
- 집으로 가져온 돈으로 사치품·기부·회사·소소한 소비
- 구매한 물건과 선택은 나의 방과 삶의 방향에 영구 기록

별도 API나 서버 없이 브라우저 저장소를 사용하며 모바일과 PC에서 실행됩니다.
