# 한 판만

복고 카지노 숫자 보드 로그라이크 웹게임입니다.

## 플레이

숫자 타일을 4×4 보드에 놓아 가로·세로·대각선 조합을 만드세요. 한 판이 끝날 때 돈을 챙기거나 전부 다시 걸어 배율을 올릴 수 있습니다. 8번째 도박장을 통과하면 정식 승리 후 무한 모드에 진입할 수 있습니다.

## 포함된 기능

- 4×4 숫자 보드와 8종 이상의 조합 판정
- 현금화 / 전부 다시 걸기 push-your-luck
- 상호작용하는 규칙 장치 15종
- 순환하는 보스 규칙 4종
- 일반 런, 정식 승리, 무한 모드
- 기기별 최고 기록 저장
- 모바일·PC 반응형 UI와 설치형 웹앱(PWA)

별도 API나 서버 없이 정적 웹 호스팅에서 실행됩니다.
