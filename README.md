# 한 판만 — 인생 모드 v5

세 장 짝 맞추기 + 위험 관리 + 생활 경제 로그라이크. 게임머니만 사용하며 실제 도박·대출·결제 기능은 없습니다.

## 생존 규칙

- 하드: 일회성 시작금 1,200, 대출 하루 복리 8%. 지옥: 900 / 14%.
- 매 판 자신의 현금을 지불합니다. 금화/장미/해골 가중치는 48/34/18.
- 한 쌍 배당 0.6/0.9/1.4배, 트리플 3/5/10배. 원금 포함 지급이므로 당첨해도 손해일 수 있습니다.
- 원하는 패 고정 및 유료 다시 뽑기. 누적금 재도전은 꽝에 소멸, 배율 최대 4배.
- 3판 안에 테이블 판돈의 4배를 당첨 합계로 달성해야 다음 테이블 진출. 판돈은 테이블마다 약 65% 상승. 6테이블 완주.
- 미결 패를 포기하고 귀가하면 이전 누적금도 소멸합니다.
- 한 번이라도 플레이하고 귀가할 때만 하루 경과, 생활·주거비, 대출 이자와 사업 손익 발생.
- 대출은 최초 계약에서 5일 후 만기. 추가 대출은 만기를 연장하지 않음. 만기 빚·미납금은 카지노 입장과 구매를 막음.
- 대출 한도는 처분 가능한 재산에 연동. 현금·청산 자산·가용 대출로 미납금, 만기 빚과 최소 판돈을 감당하지 못하면 파산.
- 39종 상품: 사치품 20, 사업 8, 기부 5, 작은 소비 6. 사치품 매각 60%, 사업 매각 50%. 기부·소비는 환불 불가.
- 6단계 집: 고시원/원룸/작은 주택/아파트/펜트하우스/저택. 현재 집 80% 처분 후 새 집 매입. 각 주거비 별도.
- 사업: 휴업 25%, 평일 40%, 성황 35%. 휴업에도 운영비 발생.
- 파산 또는 새 출발 시 재산·빚 초기화, 최근 20개 인생 기록 유지.

## 저장과 실행

정적 HTML/CSS/JS. GitHub Pages에서 동작. 매 행동을 localStorage `hanpan-life-v5`에 저장하며 진행 중인 밤과 선택 화면도 복원합니다. 기기 간 동기화 없음. 이전 `hanpan-life-v3` 저장은 삭제하거나 합산하지 않습니다. 브라우저 데이터 삭제 시 기록도 사라집니다.
